# 42 Exam Rank 06 (`mini_serv`)

## 📖 概要 (Overview)
このリポジトリは、42ネットワークのカリキュラムにおける **Exam Rank 06** (`mini_serv`) の課題をクリアするためのコードを管理しています。
この課題の目的は、C言語のソケットプログラミングと `select()` 関数を用いて、I/O多重化（マルチプレキシング）を利用した単一スレッドのシンプルなマルチクライアントチャットサーバーを構築することです。

## 🎯 学習目標 (Objectives)
* **ソケット通信**: TCPプロトコルを利用した `socket`, `bind`, `listen`, `accept` の使い方を学ぶ。
* **I/O多重化 (Multiplexing)**: `select()` 関数を利用し、ブロックせずに複数のクライアントからの入出力を同時にさばく手法を身につける。
* **バッファ管理と文字列処理**: 受信したデータを改行 (`\n`) ごとに適切に分割し、他のクライアントへ漏れなく配信する処理の実装。

## 🚀 機能 (Features)
* クライアントの新規接続および切断の管理とブロードキャスト機能
  * 接続時: `server: client <id> just arrived`
  * 切断時: `server: client <id> just left`
* メッセージのブロードキャスト機能
  * 発言者のIDとともに `client <id>: <message>` の形式で、他の全接続クライアントにメッセージを送信。
* ファイルディスクリプタの監視（`select` を用いた読み込み・書き込みの管理）
* メモリリークやセグメンテーションフォールトを回避する堅牢なエラーハンドリング。
